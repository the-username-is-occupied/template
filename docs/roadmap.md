# Roadmap
> На данный момент есть локальные прототип MVP

- Релиз mvp для приватный бета-тест с несколькими авторами, в первую очередь качество ответов и удобство подготовки (onboarding). Бесплатно
- Приватный тест с аудиторией авторов. Теперь автор может дать аудитории ссылку и на базу чтобы они позадавали вопросы. Бесплатно
- Учет фидбека и реализация монетизация
- Масштабирование на больше кол-во авторов
