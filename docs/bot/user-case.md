Добрый день.

AI ассистент поверх контента, например, Telegram/YouTube каналов. Пользователь задает вопрос в свободной форме и получать точный, персонализированный ответ, заземлённый на материалах из базы и с прямыми ссылками на оригинальные источники.

Чтобы не говорить абстракциями, есть интерфейс в виде тг бота с несколькими тестовыми базами. Попробовать вот тут


Вопрос к аудитории:

Интересен ли функционал Вам как потребителям контента: собственная базы (избранное, тематическое и пр.), заружать туда файлы, текст, ссылки, репосты, целые ютуб/тг каналы.

По умолчанию:
отправить текст или аудио - вопрос. 
Аудио - получить расшифровку.
Проверить является ли запрос валиадным.

1. Создать базу
2. Управление базой:
    - добавить src в базу (mode add - переход в ask мод)
    - удалить src из базы
    - установить системный промпт
    - удалить базу
    - переименовать

Добавление src в базу:
 - ссылка на тг канал/пост, ссылка на YT канал/плейлист/видео, файл, текст, репост


Выбор базы знаний - переход в ask мод активной бд
