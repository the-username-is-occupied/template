# Eolithic.io — Описание продукта MVP-ready)

## Видение и Миссия
**Домен:** [eolithic.io](https://eolithic.io)  
**Девиз:** *Eolithic. Carved truth.*  

**Миссия:** Дать каждому эксперту **цифрового ИИ-двойника** — постоянно обновляемое, заземлённое на источники продолжение его экспертизы, которое отвечает на вопросы аудитории 24/7 и приносит пассивный доход. Мы превращаем эфемерный поток контента (Telegram, YouTube, obssidian, Notion и другие источники) в **живой граф знаний** — compounding knowledge asset, который становится умнее с каждым новым постом и каждым заданным вопросом.

---

## Проблематика

### Для Экспертов (Создателей)
- **«Проклятие лички»:** Занятые эксперты завалены повторяющимися вопросами от аудитории — нет времени на глубокую работу.
- **Устаревание контента:** Ценные инсайты в Telegram и YouTube тонут в ленте и теряются навсегда.
- **Разрыв в монетизации:** Архив знаний не приносит пассивного дохода, хотя содержит ответы на сотни вопросов.
- **Отсутствие воронки:** Аудитория, не готовая к покупке дорогого курса, не имеет способа заплатить эксперту «чуть-чуть» и распробовать его экспертизу.

### Для Пользователей (Аудитории)
- **Информационный шум:** Поиск ответа в сотнях постов или часах видео занимает десятки минут.
- **Проблема доверия:** Обычные LLM галлюцинируют и не ссылаются на источник.
- **Отсутствие микроплатежей:** Нет способа заплатить эксперту за один ответ — только крупные продукты (курсы, консультации).

---

## Решение: Платформа Eolithic

Eolithic — двусторонняя платформа. Эксперты подключают источники и получают **автоматически обновляемую Базу Знаний** (LLM Wiki). Пользователи задают вопросы к этой базе и платят **только за вычислительную стоимость ответа + сервисную наценку + роялти эксперту**.

---

## Архитектура: LLM Wiki (паттерн Karpathy)

В основе платформы лежит паттерн **LLM Wiki** — persistent knowledge base, которая не переизвлекает знания с нуля при каждом запросе, а инкрементально обновляется с каждым новым источником.

### Три слоя данных

| Слой | Описание | Доступ |
|------|----------|--------|
| **Raw Sources** | Исходные файлы: посты Telegram, транскрипции YouTube. Неизменяемы. | Только чтение |
| **Wiki** | LLM-генерируемые markdown-страницы: сводки источников (`sources/`), сущности (`entities/`), темы (`topics/`), индекс (`index.md`), лог (`log.md`). | Чтение и запись (LLM) |
| **Schema** | Правила разметки, тиры доступа, формат страниц. Настраивается экспертом и платформой. | Эталон для LLM |

### Преимущества перед классическим RAG

| Классический RAG | LLM Wiki (Eolithic) |
|------------------|----------------------|
| Дробит сырые посты на чанки | Чанки уже структурированы в осмысленные страницы |
| Ищет эмбеддингами по всем чанкам заново | Ищет по `index.md` — оглавлению (2–5 КБ) |
| Теряет связи между темами | Связи проставлены в YAML-фронтматтере и перекрёстных ссылках |
| Не видит противоречий | Противоречия явно отмечены при ingest |
| Цитаты — сырые куски текста | Цитаты — кликабельные ссылки на оригинальные посты и таймкоды |
| Знания переизвлекаются каждый запрос | Знания компилируются один раз и накапливаются (compounding) |

## Ключевые функции

### A. Для Экспертов: Конструктор Озера Знаний

#### Онбординг (единоразово, ≤15 минут)

**1. Подключение источников**
- Ссылка на Telegram-канал → парсер забирает историю постов
- Ссылка на YouTube-канал → транскрипции + метаданные
- В будущем: Notion, подкасты, статьи, файлы

**2. Автоматическая индексация (Ingest)**
Платформа автоматически:
- Создаёт сводку каждого источника (`sources/`) с YAML-фронтматтером: дата, темы, сущности, ссылка на оригинал (`source_url`)
- Обновляет или создаёт страницы сущностей (`entities/`), дополняя их новыми инсайтами
- Обновляет тематические страницы (`topics/`) и проставляет перекрёстные ссылки
- Поддерживает `index.md` в актуальном состоянии
- Пишет хронологический `log.md`

**3. Разметка по тирам доступа (MVP — только бесплатный, позже платные)**

Разметка производится крупными блоками (канал целиком или временной период):

| Тир | Доступ | Назначение |
|-----|--------|------------|
| **Публичный** | Бесплатно | Открытый контент. Участвует в бесплатных ответах. Привлекает аудиторию. |
| **Стандартный** | Платно, базовая наценка | Полезный контент за умеренную плату (будет в будущем) |
| **Премиум** | Платно, повышенная наценка | Ценный контент, углублённые материалы (будет в будущем) |
| **Эксклюзив** | Платно, максимальная наценка | Редкие инсайты, уникальный опыт (будет в будущем) |
| **Закрытый** | Недоступен | Личное, черновики, не участвует в базе |

**На старте:** только публичный тир. Эксперт бесплатно оцифровывает знания, привлекает аудиторию, получает микророялти. Платные тиры включаются по запросу эксперта.

#### Дашборд эксперта (ongoing)

```
Аналитика
├── Количество запросов за период
├── Самые популярные темы и сущности
├── Заработок и история роялти
├── Какие источники используются чаще всего
└── Отчёт линтинга: противоречия, устаревшие данные, пробелы

База
├── Статус индексации и дата последнего обновления
├── Добавить новый источник
├── Изменить разметку (позже)
└── Запустить линтинг (проверка здоровья wiki)
```

**Что эксперту делать не нужно:** думать о чанках и RAG, писать промты, настраивать модель, модерировать ответы. Эксперт принимает три решения — *что подключить*, *что открыто*, *сколько стоит платный доступ*. Всё остальное — автоматически.

### B. Для Пользователей: Интеллектуальный ассистент

#### Флоу запроса

1. Пользователь выбирает базу эксперта (или глобальный поиск по всем базам)
2. Пишет вопрос
3. Система выполняет **routing** — поиск релевантных страниц по `index.md` базы
4. Система читает найденные wiki-страницы и генерирует ответ **строго на их основе**
5. В ответе — прямые кликабельные ссылки на оригинальные посты в Telegram и таймкоды YouTube

#### Прозрачная стоимость

В MVP пользователь платит **только за вычислительную стоимость**, а не за доступ к знаниям:

```
Себестоимость ответа: $0.003–0.03 (зависит от модели)
Сервисная наценка:    $0.002
Роялти эксперту:      $0.002–0.02
─────────────────────────────────
Итого с пользователя: ~$0.01–0.05
```

Перед генерацией ответа система показывает финальную стоимость одной цифрой. Никаких сложных разбивок по тирам в MVP — только итоговая цена. Пользователь подтверждает — система генерирует ответ.

#### Бесплатный тизер и демо-кредиты

- Пользователь получает **сокращённый ответ** бесплатно
- Полный ответ с цитатами и источниками — платный
- 3–5 **демо-кредитов** новым пользователям (полные ответы бесплатно, чтобы распробовать)
- Демо-кредиты — это customer acquisition cost платформы

#### Политика нулевых галлюцинаций

- Ответ генерируется **строго** на основе найденных wiki-страниц
- Если ответа нет в базе — ИИ честно сообщает: «Эксперт не освещал эту тему»
- Каждое утверждение сопровождается кликабельной ссылкой на **оригинальный источник** (пост в Telegram или таймкод YouTube)

## Экономическая модель (MVP)

### Себестоимость одной индексации источника (Ingest)

Один новый пост/видео — несколько LLM-запросов:

| Операция | Модель | Стоимость |
|----------|--------|-----------|
| Создание сводки источника | GPT-4o-mini | ~$0.00048 |
| Обновление сущностей (×3) | GPT-4o-mini | ~$0.00159 |
| Обновление index.md + log.md | GPT-4o-mini | ~$0.00243 |
| **Итого 1 источник** | | **~$0.0045** |

*С бесплатным тиром Gemini Flash — $0.00. С DeepSeek-V3 — ~$0.008.*

### Себестоимость одного запроса пользователя (Query)

| Операция | Модель | Стоимость |
|----------|--------|-----------|
| Роутинг (поиск по index.md) | GPT-4o-mini | ~$0.00054 |
| Генерация ответа | GPT-4o-mini | ~$0.00176 |
| Пост-обработка (20% запросов) | GPT-4o-mini | ~$0.00019 |
| **Итого 1 запрос** | | **~$0.0025** |

*При использовании DeepSeek-V3 — ~$0.004. Gemini Flash — $0.00.*

### Источники дохода платформы (MVP)

| Источник | Описание |
|----------|----------|
| **Наценка на запрос** | Платформа берёт маржу с каждого платного запроса (~$0.002) |
| **Роялти-пул** | Часть цены запроса распределяется между экспертами пропорционально использованию их контента |

В будущем: комиссия с подписок на платные тиры, корпоративные лицензии.

### Кошелёк пользователя (будущая версия)

- Пополняемый кошелёк в реальной валюте
- Списание по факту подтверждённого запроса
- В MVP — минимальная реализация или отложена

## Технологический стек (MVP)

| Компонент | Технология/Подход |
|-----------|-------------------|
| **Парсеры** | Telegram API (Telethon/GramJS), YouTube Transcript API. Модульная архитектура для новых источников |
| **Хранение** | Файловая система: `raw/` для сырых источников, `wiki/` для markdown-страниц. Git-репозиторий для версионирования |
| **Поиск (routing)** | LLM читает `index.md` (2–5 КБ) и возвращает список релевантных страниц. Без векторной БД на старте |
| **Генерация** | GPT-4o-mini (основная), DeepSeek-V3 (резерв), Gemini Flash (бесплатный резерв). Промты с требованием цитировать `source_url` |
| **Биллинг** | В MVP — минимальный (учёт платных запросов). Полноценный кошелёк — позже |
| **Фронтенд** | Веб-интерфейс: выбор эксперта, поле вопроса, отображение цены, ответ с кликабельными ссылками на источники |
| **LLM Wiki** | Трёхслойная архитектура: raw → wiki → schema (паттерн Karpathy) |

## Конкурентный анализ и место в воронке эксперта

### Eolithic vs Курсы и Консультации

| | Eolithic | Курс эксперта |
|--|----------|---------------|
| **Что продаёт** | Ответ на конкретный вопрос | Система, методология, трансформация |
| **Цена** | $0.01–0.05 | $200–2000 |
| **Время** | Мгновенно | Недели-месяцы |
| **Когда нужно** | «Прямо сейчас болит» | «Хочу научиться» |
| **Аудитория** | Все подписчики | 1–3% подписчиков |

**Eolithic не конкурент курсам — это воронка.** Пользователь, который задал 10+ платных вопросов, с высокой вероятностью купит курс, когда будет готов к трансформации. Eolithic даёт эксперту способ монетизировать тех, кто никогда не купит курс — и растить тех, кто купит.

## Стратегия выхода на рынок (Go-to-Market)

### Этап 0 — Валидация без кода (1–2 недели)
- Ручной эксперимент: 1 эксперт, 10 пользователей, 5 вопросов
- Эксперт даёт доступ к 30 постам — вы вручную ищете ответы и показываете пользователям
- Замер готовности платить: «Вы бы заплатили цент за такой ответ? А пять центов?»

### Этап 1 — Якорные эксперты (Месяцы 1–3)
- Фокус на СНГ: Telegram как основной источник
- Онбординг 3–5 средних экспертов (50k–200k подписчиков) в нишах IT, Финансы, Маркетинг
- Эксперт приводит аудиторию: один пост-анонс в канале
- Приоритет: качество парсинга, скорость ответа, точность retrieval
- Критерий успеха: первые платные запросы, положительные отзывы

### Этап 2 — Запуск маркетплейса (Месяцы 4–6)
- Открытие платформы для новых экспертов
- Публичный каталог баз знаний с бесплатным входным слоем
- Реферальные ссылки для экспертов

### Этап 3 — Масштабирование (Месяц 6+)
- Платные тиры доступа (по запросу экспертов)
- Подписки на базы (альтернатива per-query)
- Расширение источников: подкасты, Substack, Notion
- Корпоративные продажи (White-label)

## Ключевые отличия (USP)

1. **LLM Wiki, а не RAG:** Знания накапливаются и обновляются, а не переизвлекаются с нуля при каждом запросе. Качество ответов растёт с каждым новым источником (compounding).
2. **Прозрачная стоимость:** Пользователь видит точную цену до подтверждения. Платит за compute, а не за контент (в MVP).
3. **Заземлённая истина:** Каждое утверждение — кликабельная ссылка на оригинальный пост или таймкод видео.
4. **Пассивная монетизация:** Эксперт подключает канал один раз — зарабатывает на каждом платном запросе к своей базе.
5. **Справедливые роялти:** Оплата пропорциональна реальному использованию источников эксперта.
6. **Не конкурент курсам, а воронка:** Eolithic монетизирует «неготовых к курсу» и подогревает их к крупной покупке.

## Риски и стратегии смягчения

| Риск | Стратегия смягчения |
|------|---------------------|
| **Качество парсинга** | Ручное тестирование на первых экспертах. Приоритет Telegram API |
| **Пользователь не платит** | Демо-кредиты, бесплатный тизер, валидация спроса ручным экспериментом до кода |
| **Эксперт не верит в модель** | Показать микро-роялти с первых дней. Апеллировать к пассивности и разгрузке лички |
| **Высокая стоимость LLM** | Мульти-провайдер: GPT-4o-mini как основной, Gemini Flash как бесплатный резерв, DeepSeek-V3 как дешёвый запасной |
| **Каннибализация курсов** | Объяснение эксперту: Eolithic = аптека, курс = университет. Одно не заменяет другое |
| **Рост цен API** | Диверсификация провайдеров. Миграция на open-source модели при масштабировании |
| **Авторские права** | Чёткие ToS: эксперт подтверждает права на загружаемый контент |
| **Регуляторика кошелька** | Отложена на этап после MVP. На старте — минимальный учёт платных запросов |
| **Холодный старт** | Решается через модель «эксперт приводит аудиторию» |

## Финансовый прогноз MVP (месячная экономика)

**Допущения:** 3 эксперта, 300 новых источников/мес, 1000 платных запросов/мес.

| Статья | Сумма |
|--------|-------|
| Индексация (300 источников × $0.0045) | $1.35 |
| Запросы (1000 × $0.0025) | $2.50 |
| Сервер + домен | $15 |
| Cursor + GitHub | $24 |
| **Итого расходы** | **~$43** |
| Доход (1000 запросов × $0.01) | $10 |
| **Дельта** | **−$33** |

*Сервис убыточен на старте при 1000 запросах, но это плановая инвестиция. Точка безубыточности при 3 экспертах — ~4300 платных запросов в месяц. С ростом баз и включением платных тиров — выход в плюс.*

*При использовании Gemini Flash (бесплатно) — точка безубыточности ниже.*

## Заключение

Eolithic превращает потоковый контент в **compounding knowledge asset**. Эксперт получает пассивный доход и разгрузку лички. Пользователь — мгновенные точные ответы с проверяемыми источниками. Платформа строится на паттерне LLM Wiki — не переизобретает RAG, а реализует следующий шаг эволюции персональных баз знаний.
