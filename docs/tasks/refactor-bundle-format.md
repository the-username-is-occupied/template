Необходимо выполнить рефакторинг формирования бандлов и резовлинга цитата.
На данный момент имеем неэффективную компановку текста в md (BundleRenderer).

Новый формат:

# [ID_Уникальный_Номер]
**Метаданные:**

* **Base64:** 
* **Дата:** 
* **Ссылка:** url тг поста/youtube video
* **Просмотры:** 
* **Тип:** [Пост / Комментарий / Фото / Расшифровка ]
* **Реакции:** ❤️ (46), 🔥 (12) <!-- («развернуть» (десериализовать) json или array при наличии) -->
* **Связи:** 
    * **Родительский пост:** [ID_Родителя]
    * **Связанные посты:** [ID_123], [ID_456]

**Текст поста:**
Здесь размещайте основной контент сообщения...

--- <!--  Дополнительный визуальный разделитель -->

# [Следующий пост]

Конечный формат метаданных зависит от type (App\Enums\SourceType) ContentSource которому принадлежит OriginalItem
